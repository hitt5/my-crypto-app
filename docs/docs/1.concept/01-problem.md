# 01 — 課題認識（Problem）

> **標準**: [`README.md`（コンセプト設計標準）](README.md) の品質バーに従う。

## 現状の問題

### 1. オペレーショナルαの取りこぼし（継続不能な手作業）

オンチェーンの資産形成には「地味だが大量にある作業」が本命の収益源（オペレーショナルα・インセンティブα）として存在するが、人間には継続できない。

- 毎日数百のプロトコル・ガバナンスフォーラム・GitHub 更新の巡回
- 金利・報酬・TVL・流動性の変化検知
- エアドロップの Eligibility 条件と期限の管理、Claim 可能の検知
- 不要な Token Approval の解除（放置はセキュリティリスク）
- 資産配分の乖離検知とリバランス
- 税務用の取得価格・取引理由の記録

### 2. 表面利回りによる誤った投資判断

画面に表示される APY だけを比較して投資すると、報酬トークンの価格下落・スマートコントラクト障害・ブリッジ障害・デペッグ・流動性不足・管理者権限・オラクル操作を織り込んだ**リスク調整後収益がマイナス**の案件に資金を入れてしまう。期待純収益（基礎金利＋報酬＋インセンティブ期待値−ガス−スリッページ−ヘッジ費用−税務コスト−期待損失）での評価が個人には実務上不可能。

### 3. 既存自動売買の構造的欠陥（FX 自動売買の再来）

- 「戦略を選ぶ → API キーを渡す → ブラックボックスが売買する」という丸投げ構造。権限の可視化も判断根拠の追跡もできない
- AI に価格予測をさせて売買回数を増やすと、手数料・スリッページ・ノイズ取引が増えて、FX 自動売買と同じ構造で負ける（価格予測αは再現性が最も低い）
- Agent は疲れないが「市場ノイズに反応し続ける」という別の弱点を持つ — 回転数の上限がなければ損耗する

### 4. 危険からの退避が人間頼み

ステーブルコインのデペッグ、Oracle 異常、TVL 急減、Admin key 変更、Contract upgrade、Governance 攻撃、Bridge 停止、フロントエンド改ざん — これらの検知と退避（新規取引停止・Approval 解除・安全資産への移動）が人間の気づきに依存している。**損失を一度回避する価値は、細かいトレードで数年間稼ぐ利益より大きい**可能性があるのに、最も自動化されていない。

### 5. 投資判断の知が蓄積されない

どんな Opportunity があったか、どの情報源が正しかったか、なぜ投資したか、どのリスクを見落としたか、何もしない方がよかったか — これらが記録されず、失敗から学習できない。「ウォレット全体で増えた」だけでは Agent 介入の増分利益を測れない。

## なぜ今やるのか

- **Smart Account / Session Key の成熟**: Safe の Module/Guard、Intent 型執行（CoW Protocol 等）により、「秘密鍵を渡さず、期限付き・用途限定の権限だけを委任する」アーキテクチャが実装可能になった
- **Agent 基盤の成熟**: dodoAI の SDT / Multi-Agent / HIL / Evidence により、「暴走しない・説明できる・権限を奪えない」AI を統治構造ごと構築できる
- **規制の移行期（2026）**: 金融庁 WG で暗号資産を金商法上の金融商品として扱う方向が示され、制度移行期にある。「実行前承認を標準」「ユーザー定義ルールの機械的実行」「自己勘定支援」という設計を最初から選ぶことで、規制適合と差別化を両立できる
- **競争軸の選択**: 運用成績の競争はクオンツ・取引所・ファンドとの正面衝突。今なら「権限の可視化・判断根拠の追跡・Agent 統治」という別の防衛線を先に築ける

## 放置した場合のリスク

| リスク | 影響 |
|---|---|
| 手動運用の継続不能 | エアドロップ・Claim・金利機会の恒常的な取りこぼし。Approval 放置によるセキュリティ露出 |
| 表面 APY での投資継続 | リスク調整後マイナスの案件への資金投入。コントラクト障害・デペッグ時の全損 |
| 既存ボット型（API キー丸渡し）の採用 | 権限の不可視化・ブラックボックス化。高回転売買による手数料負け（FX の再来） |
| 危険検知の人間依存 | デペッグ・脆弱性・ガバナンス攻撃発生時に退避が間に合わず大幅損失 |
| 判断記録の不在 | 同じ失敗の反復。戦略の良否を「相場のせい」と切り分けられない。税務対応コスト増 |
| 規制動向の無視 | 助言・媒介・運用該当による事業リスク（ノンカストディアルでも対象になり得る） |
