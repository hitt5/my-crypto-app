## 3値判定（Designed ↔ Implemented 照合を行う場合）

| 判定 | 意味 |
|------|------|
| **ALIGNED** | 設計意図と実装事実が一致 |
| **DRIFTED** | 乖離を検出（是正 Issue を起票する） |
| **UNKNOWN** | 照合材料不足（🔴未確認として残し、創作で埋めない） |

## HIL（Human-in-the-Loop）ゲート

| # | フェーズ | 人間が判断すること | 状態 |
|---|---------|-----------------|------|
| H1 | Phase 0 後 | アプローチ承認 | ⬜ |
| H2 | Phase 1/2 後 | 着手対象の選定 | ⬜ |
| H3 | 成果物生成後 | 生成物と現行挙動・業務の一致確認 | ⬜ |
| H4 | 改修着手前 | 改変範囲・方針の承認 | ⬜ |

## 評価レポート

判定結果・根拠・残課題を記録する。
