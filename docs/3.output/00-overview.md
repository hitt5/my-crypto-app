## なぜここに成果物を置かないのか

1. **二重管理の防止** — 成果物は機械生成であり、SDT/ART（`99.sdt/art/`）が SoT。コピーを置くとドリフトする
2. **再生成可能性** — 生成手段（Action）と合格条件は [2.manual/01.structuring/](../2.manual/01.structuring/01-procedure.md) に記録済み
3. **トレーサビリティ** — AGN の trace / spec_refs から `99.sdt/art/` を直接参照する
